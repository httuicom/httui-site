Esta guía te lleva desde un install limpio de httui hasta correr tus
primeros bloques HTTP y SQL. ~10 minutos.

## Instalar

httui es una app de escritorio (Tauri) + un binario de terminal (TUI).
Cada release publica installers listos; también puedes buildar desde
el código.

### Script de instalación (macOS & Linux)

```bash
curl -fsSL https://httui.com/install.sh | sh
```

Resuelve la última release e instala el `.app` en macOS (limpiando
la cuarentena de Gatekeeper) o el AppImage en Linux.

### Homebrew (macOS & Linux)

```bash
brew tap httuicom/httui
brew install --cask httui
```
