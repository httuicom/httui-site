Este guia leva você de um install limpo do httui até rodar seus
primeiros blocos HTTP e SQL. ~10 minutos.

## Instalar

httui é um app desktop (Tauri) + um binário de terminal (TUI).
Toda release publica installers prontos; também é possível buildar
a partir do código.

### Script de instalação (macOS & Linux)

```bash
curl -fsSL https://httui.com/install.sh | sh
```

Resolve a última release e instala o `.app` no macOS (limpando
a quarentena do Gatekeeper) ou o AppImage no Linux.

### Homebrew (macOS & Linux)

```bash
brew tap httuicom/httui
brew install --cask httui
```
